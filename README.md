# Studio MVP ✏️

Studio is an AI-adaptive collaboration platform that builds a custom workspace for any team — creative, technical, operational, social, or community-driven.

## Features

- 🤖 **AI Assistant "Sketch"** — integrated like a team member, accessible via @mention or direct chat
- 🏠 **Purpose-driven Rooms** — not generic channels, but AI-curated spaces
- 💬 **Messages with reactions** — real-time-style conversation
- 📁 **File Hub** — per-room file management
- 🗂️ **Contextual Tabs** — messages, files, overview, and room-specific panels
- 🎨 **Pastel design system** — Lora + Inter typography, lavender/blush/mint/cream palette
